# Moimoipi – Donjons Idle

Dungeon crawler automatique en pixel art, jouable sur mobile (PWA, hors ligne).

- Jouer en local : ouvrir `index.html` dans un navigateur.
- Jouer sur téléphone : activer GitHub Pages (Settings → Pages → branche, dossier `/`),
  puis ouvrir `https://<utilisateur>.github.io/moimoipi/` et « Ajouter à l'écran d'accueil ».

Voir `CLAUDE.md` pour l'architecture et l'état d'avancement.
